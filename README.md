# 🔗 URL Shortener

## 📌 Overview

URL Shortener is a web application that converts long URLs into shorter, easy-to-share links. It simplifies link sharing and provides a convenient way to access original URLs through shortened links.

## ✨ Features

- Convert long URLs into short links.
- Redirect users to the original URL.
- Generate unique short URLs.
- Simple and user-friendly interface.
- Easy link sharing.
